# Archive

This directory contains material that is useful for historical context, debugging evidence, or portfolio support, but is not required to build or run the current ROS2 stack.

## Contents

- `docs_archive/`: detailed migration notes, troubleshooting logs, and old change history
- `firmware_legacy/`: older Arduino firmware variants kept for reference
- `reference/`: external competition reference material
